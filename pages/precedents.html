5.1最高法 2025-12-29 惩治逃废债典型案例（7 件）

近两年最权威、方向最有利——直接覆盖倍富 0 元转让 / 抽逃 / 关联混同三线。

案例一 · 横向刺穿面纱

关联公司人格混同、财产不分，判决关联公司承担连带责任。→ 支撑本案"中通系/双彩关联连带"（公司法第 23 条）。

案例二 · 两次 0 元转让

股东在公司不能清偿负债时两次零对价转让股权恶意逃避出资 → 判决股东对债权人承担补充赔偿责任。→ 直接命中陆亦杰/杨周 0 元受让。

案例三 · 抽逃出资

股东转入出资 2 日后即转出、无正常交易证明 → 构成抽逃 → 判决股东对债权人承担补充赔偿。→ 支撑原股东抽逃返还（行动线5）。

案例五 · 破产阻挠清算

拒不移交财务账册、阻挠清算 → 拘留 15 日 + 罚款 10 万。→ 刑事/司法制裁威慑。

案例六 · 虚假破产罪

隐匿转移财产虚假破产 → 追究虚假破产罪。→ 衔接刑法第 162 条之二。

案例七 · 拒执罪

有能力执行而拒不执行 → 追究拒执罪。→ 衔接刑法第 313 条、南检立案监督。

重点：案例二/三的判项是「股东对公司债权人承担补充赔偿责任」——是判给债权人本人的，不是先归公司。这是倍富最想看到的表述。

5.2苏州虎丘法院 2026-03 "职业闭店人"破产案

最贴近本案的近期实例

案情：原股东将股权0 元转让给无出资能力的老人 → 破产受理。
裁判：判原股东出资加速到期补缴、受让人连带，款入破产账户。
与本案关联：与倍富"0 元转让 + 破产"场景同构——直接支撑路径 A（管理人追收）与股东 0 元转让补责论证。

5.3华星公司案（最高法公报 2019-3）

第三人独立侵权范本

案情：第三人（国资委下属担保公司）恶意无偿划转股权侵害债权。
裁判：判在受益范围内赔偿；因债务人已注销、债权未进池，赔偿直接判给债权人。
与本案关联：第三人侵权"直接赔"的范本（路径 B）；但其"直接赔"前提是债务人注销、债权未进池——双彩仍在破产，故本案通常归池，仅窄缝才直接赔。

5.4其他支撑判例

最高法二巡"不翼而飞的几千万"案（吴某诉 B、C 公司）

关联公司低价受让资产 + 破产 → 判连带，但债权纳入破产财产、全体分。→ 说明关联侵权追回款在债务人破产时归池（反衬国赔/第三人侵权窄缝才是直接赔通道）。

指导案例 118 号

不合理低价转让撤销权规则。→ 支撑民法典第 539 条撤销路径（芜湖京采等）。

指导案例 153 号

债权人在破产中可独立保护自身债权。→ 支撑"管理人怠于追收 → 个别债权人代表全体诉"。
