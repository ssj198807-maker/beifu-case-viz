04法律依据（逐条拆解 + 本案适用）

破产法 31
受理前一年内无偿/明显不合理价格转让，管理人可撤销。
本案：0 元转让落临界期可撤销；关联交易 99% 属不合理价格。
破产法 33
为逃避债务隐匿转移财产无效，无时限。
本案：0 元+保全期间转让→自始无效，覆盖 2022 首次转让。
破产法 35
破产后出资人未缴出资，管理人应追缴，不受期限限制。
本案：路径 A 追收硬义务。
解释二 21 / 23
破产后债权人诉股东直接赔偿法院不受理，须管理人追收、款归池。
本案："直接赔倍富"被阻断的根本条款。
公司法 23
股东滥用法人独立地位逃避债务，连带（横向人格否认）。
本案：关联交易 99%+资金归集+自认混同；合并破产裁定已将混同定为免证事实。
公司法 53 / 54 / 88
抽逃返还 / 加速到期 / 0 元转让补责（88 条 2024-07-01 分界）。
本案：原股东抽逃返还；0 元转让转让人补责（首次转让另寻第 33 条）。
民法典 1165 / 539
过错侵权 / 不合理低价撤销。
本案：第三人侵权窄缝（不受解释二第 21 条限制）；衔接指导 118 号。
国家赔偿法 38 / 2 / 39
违法保全赔偿 / 请求权基础 / 2 年时效（知道日起算）。
本案：迟延保全致 347 万流失；知道日 2025-02-06→届满 2027-02-06。
刑法 313 / 162之二
拒执罪 / 虚假破产罪。
本案：刑事深化（衔接最高法 2025 案例六/七）。
法〔2018〕53号 32–34
关联企业实质合并破产适用条件（人格高度混同、区分成本过高、损害公平清偿）。
本案：合并破产裁定把混同定为免证事实。

05关键判例（方向最有利）

最高法 2025-12-29 惩治逃废债典型案例（7 件）

案例一 横向刺穿面纱（关联公司连带）　|　案例二 两次 0 元转让→出让人+受让人补充赔偿（命中陆亦杰/杨周）　|　案例三 抽逃出资补充赔偿（行动线5）　|　案例五 破产阻挠清算（拘留15日+罚款10万）　|　案例六 虚假破产罪　|　案例七 拒执罪。
重点：案例二/三判项是「股东对公司债权人承担补充赔偿」——判给债权人本人，非先归公司。

苏州虎丘法院 2026-03 "职业闭店人"破产案 · 最贴近本案

原股东 0 元转让股权给无出资能力老人→破产受理→判原股东出资加速到期补缴、受让人连带，款入破产账户。与倍富 0 元转让+破产场景同构。

华星公司案（最高法公报 2019-3）· 第三人独立侵权范本

第三人恶意无偿划转股权侵害债权，判受益范围内赔偿；因债务人已注销、债权未进池，赔偿直接判给债权人。但双彩仍在破产，本案通常归池，仅窄缝才直接赔。

最高法二巡"不翼而飞的几千万"案

关联公司低价受让+破产→判连带，但债权纳入破产财产、全体分。反衬国赔/第三人侵权才是直接赔通道。

指导案例 118 号 / 153 号

118 号：不合理低价转让撤销权规则。153 号：债权人在破产中可独立保护自身债权（支撑"管理人怠于追收→个别债权人代表全体诉"）。
